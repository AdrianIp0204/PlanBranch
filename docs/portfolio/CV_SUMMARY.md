## 150 words

PlanBranch investigates how developers can retain control when using AI coding agents on evolving software projects. The local application combines React and TypeScript visual planning with a Python backend, SQLite persistence and Git worktree execution. Requirements, design alternatives, task dependencies and acceptance criteria provide context for separate decisions about approval, execution, result acceptance and applying changes. Candidate source identities connect observed changes and verification evidence, while imports and checkpoint recovery preserve historical context without granting fresh execution authority. The project supports multiple model providers, explicit repository-context consent and review of agent-generated work. Engineering evaluation uses disposable repositories, deterministic fixtures and independent acceptance checks to examine traceability, unexpected modifications and interrupted-task recovery. These observations test workflow mechanisms rather than model intelligence or productivity. A controlled direct-workflow comparison and human review study remain future work.
