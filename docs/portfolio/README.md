## Reading the evidence

**Implemented** means the behaviour has a source reference. **Observed** means a recorded check ran on identified source. **Deterministic fixture** means fixed inputs and scripted agent behaviour, even when real Git, database and verification operations ran. **Not yet conducted** means no empirical result exists. Historical release checks do not certify this branch.

The public [v0.3.1 release](https://github.com/AdrianIp0204/PlanBranch/releases/tag/v0.3.1) was published on 14 October 2026. This portfolio audit changes a feature branch; it does not replace or certify those release artifacts. The [validation record](VALIDATION.md) gives the current scope, skipped gates and artifact preservation checks.

## Application emphasis

For **CUHK Artificial Intelligence: Systems & Technologies**, explain the engineering around an uncertain model: structured intent, source identity, permissions, human decisions, and a falsifiable evaluation. These topics connect to the programme's stated emphasis on implementing AI systems with computing and mathematical foundations. That connection is an interpretation of the [official programme description](https://admission.cuhk.edu.hk/programme/aistn/), checked 26 October 2026; it is not an admissions criterion or evidence of ML research.

For **HKU's Bachelor of Engineering Elite Programme**, foreground problem definition, practical constraints, design trade-offs, testing and honest attribution. The [official programme description](https://www.admissions.hku.hk/programmes/undergraduate-programmes/bachelor-of-engineering-elite-programme) describes broad engineering opportunities; this project is one example of engineering work, not a substitute for academic requirements. For CS and data programmes, use task graphs, state transitions, persistence, provenance and measurement validity as discussion points.

Before submitting any personal statement, the owner must confirm their origin story, dates, individual design/debugging contributions, collaborators and use of AI tools. The documents deliberately avoid assigning unverified personal authorship.
