# Evidence register

This register separates **implementation**, **recorded observation** and **open hypothesis**. The current [validation record](VALIDATION.md) is authoritative for this branch's executed checks and omissions. A test's existence is not evidence that it passed on current source. The [fixture receipt](evidence/deterministic-evaluation.json) includes source identity and retains failed candidate criteria.

Baseline checkout: `60fc36b4f8a0f0d14e2c5137b77f05e9f5d8d665`. The feature branch is `codex/portfolio-engineering-audit`. The evidence accompanies changes made after that commit; use the receipt's source fingerprint and the [validation source manifest](evidence/source-manifest.json), not baseline HEAD alone, to identify observed working-tree bytes. Git line-ending normalization can change byte fingerprints in a fresh checkout; CI must test its own checkout and artifacts. Re-run checks after relevant changes.

## Reproducing claims responsibly

Use a clean test environment and follow [VALIDATION](VALIDATION.md) and [EVALUATION](EVALUATION.md). Preserve nonzero exits, skipped tests and negative fixtures. Do not rerun paid providers merely to imitate a result, relabel simulated output as observed verification, or count scripted decisions as human study participants. Public evidence includes only disposable examples and source hashes; local logs can contain machine paths and must be reviewed before sharing.
